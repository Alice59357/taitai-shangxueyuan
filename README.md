# 太太商学院 · 万紫帆

女主力 · 人生重塑 · 星火之年

这是太太商学院的静态品牌主页，由 GitHub Pages 从 `main` 分支根目录发布。

## 本地预览

在仓库根目录执行：

```bash
python3 -m http.server 8080
```

浏览器打开 [http://localhost:8080](http://localhost:8080)。

## 文件

- `index.html`：页面
- `assets/hero.jpg`：活动海报主视觉
- `assets/styles.css`：样式
- `assets/main.js`：菜单开关与页头
- `.nojekyll`：让 Pages 按原样发布静态文件，不经 Jekyll 处理
